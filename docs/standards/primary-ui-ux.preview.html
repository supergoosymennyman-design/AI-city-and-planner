Separation rules
  • Clearly not KG: cool palette, geometric Sora type, data panels — no Bo, no sticker bounce.
  • Capable, not coddling: real numbers, trade-offs, optimization — older kids feel trusted.
  • AI is a tool: the Advisor suggests & explains; the child stays the decision-maker.
  • Still accessible: two-channel, ≥44px targets, Canvas map has a keyboard/PDOM mirror, CVD-safe system colours.
  • Deterministic sim: fixed-point, seeded — same inputs → same city (the City contract).
