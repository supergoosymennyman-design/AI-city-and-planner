Separation rules

  • Clearly not KG: cool teal + electric lime, Bricolage type, glowing command screens, isometric city — no Bo, no sticker bounce.
  • Capable, not coddling: real numbers, trade-offs, optimisation — older kids feel trusted.
  • AI is a tool: the Advisor suggests & explains; the child decides.
  • Still accessible: two-channel, ≥44px targets, Canvas has a keyboard/PDOM mirror, CVD-safe system colours, high contrast on the dark deck.
  • Deterministic sim: fixed-point + seeded — same inputs → same city.
