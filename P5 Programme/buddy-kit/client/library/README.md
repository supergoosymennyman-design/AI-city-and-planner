# Shared 3D Model Library

The single place-able-object library for the AI City sim (and future scenarios).
Consumed by `city-common/library.js` (the data catalog) and loaded via GLTFLoader.

## License policy — CC0 / public domain ONLY

Every model in this library must be **free for unrestricted commercial use** —
CC0 / public domain (Kenney, Quaternius, KayKit, objcar, planets). Models that
require attribution (CC-BY), forbid commercial use (CC-BY-NC), or have an
unverified license (itch "personal-use" packs, Sketchfab downloads, mixed
provenance) are **not allowed** and have been removed.

- See **`CC0-MANIFEST.md`** in this folder for the authoritative keep list.
- The 4 interior scenarios (hospital/lab/spaceship/station) were removed; their
  placeholder buttons remain on the hub until rebuilt with CC0 content.

## Conventions — every model MUST be

- **GLB** (glTF binary), produced by the Blender "library-normalize" script
  (`../../../scripts/library-normalize.py`).
- **CC0 / public-domain licensed** — this is the hard rule.
- **Meter-scaled, real world units** — a chair is ~0.9 m, a building ~20 m.
- **Base on `y=0`** (feet/floor at origin height), centred on X/Z.
- **≤ 2 materials** per model (merge by material), single merged geometry where
  possible — the draw-call rule we enforce for low-end tablets.
- **Low-poly** (typical game pack level). Detailed hero assets allowed for the
  champion / special quest buildings, not for library filler.

## Categories

| Folder | What goes in |
|---|---|
| `buildings/` | Buildings and structures (Kenney City Kit, Quaternius Ultimate Buildings…) |
| `nature/` | Trees, plants, rocks, ground cover (Quaternius Nature, Kenney Nature…) |
| `props/` | Furniture, lab equipment, street props, signs (Kenney Furniture/Factory…) |
| `vehicles/` | Cars, buses, taxis, ships (Kenney Car Kit, Quaternius Transport…) |
| `characters/` | Non-champion characters / creatures (Quaternius Base Characters, Kenney Cube Pets…) |
| `scenarios/` | Theme sets (CC0 packs only) |

## File naming

`<source>-<thing>.glb` — e.g. `kenney-city-commercial.glb`, `quaternius-lab-cabinet.glb`.
Keep the source prefix so curation stays greppable.

## How to add a model

1. Download the source (FBX/OBJ/GLB) — **must be CC0 / public domain**.
2. Open Blender, run `library-normalize.py` (via Blender MCP or Text Editor).
3. Save the exported GLB into the right category folder.
4. Add an entry to `city-common/library.js` (id, name, emoji, glb path, footprint/scale).
5. Regenerate thumbnails (`scripts/generate-thumbnails.mjs`).

## Cloud hosting / scaling (R2-ready)

- **Now:** `library/` is copied into each Workers deploy and served at `/library/...`
  (relative paths in `library.js`). Fine up to ~tens of MB.
- **When the library grows (hundreds/thousands of models):** move the GLB files to
  **Cloudflare R2** behind the CDN, set `LIBRARY_BASE` in `city-common/library.js`
  to that origin, and load via `libraryUrl(item)`. No other code changes.
- **Thumbnails** for the picker UI live in `library/thumbnails/<id>.png`, generated by
  `scripts/generate-thumbnails.mjs` (renders each model headlessly via Playwright).
  Regenerate after adding models: `node scripts/generate-thumbnails.mjs`.
