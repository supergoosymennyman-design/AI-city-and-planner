## The shared scenario runtime (know this cold)
- `client/shared/scenario.js` — `mountScenario(config)`: boots a scenario,
  wires the champion, grab/select/pick-up/place, wall-fade, ceiling-fade,
  two-zone `zones` (outside/inside with 🚪 Enter/Exit), and **height-aware
  movement** (raised platforms + stairs).
- `client/shared/room-builder.js` — `buildMultiRoom(scene, plan)` builds the
  **procedural multi-room interior**: banded walls, grid floors colour-coded
  per room, partition walls with door gaps, **raised platforms with stairs**,
  colliders. Returns `{walls, ceiling, colliders, floor, dims, platforms}`.
- `client/shared/interior.js` — materials, `buildRoomShell`, lights, wall/ceiling
  fade, collider helpers.
- `client/shared/grab.js` — interaction system.
- `client/shared/scenario-buddy.js` — the Champion chat adapter.
- `client/city-common/library.js` — the model catalog (~1420 entries):
  `{id, name, emoji, glb, category, footprint, height, anchors, picker, drivable}`.
  **Any furniture id used in a template MUST exist here or it silently skips.**
- `client/shared/gltf.js` — `createGLTFLoader()` (Draco + Meshopt decoders).
  **NEVER construct a raw `GLTFLoader` in new code** — 70+ Sketchfab GLBs are
  Draco/Meshopt-compressed and silently fail without this.

## The `plan` shape for `buildMultiRoom`
```js
{
  w, d, h, gridStep,               // outer footprint
  hull: { wall, baseboard, trim, ceiling, lightPanel, cove, frame, grout, floor, walk, inlay },
  entryDoor: { side:'s', cx, cw } | null,
  rooms: [ { id, x, z, w, d, ringR, palette: { floor, grout, trim, accent, emissive, lightPanel, inlay, walk, ring } } ],
  partitions: [ { axis:'x'|'z', x, z, w, d, side, door?:{cx,cw} } ],
  platforms: [ { x, z, w, d, topY, stairSide:'n'|'s'|'e'|'w', stairW, color, stepColor, emissive } ],
}
```
- `axis:'x'` = horizontal wall at fixed z spanning x; `axis:'z'` = vertical at
  fixed x spanning z. `door` carves a gap.
- Platforms: the champion climbs the stairs (ground-height resolver + auto
  step-up, `STEP_MAX=1.5`), stands/walks on top, falls off edges. Stairs go
  outward from the chosen side; the climb reaches full height at the wall face.

## Config extras available on a template
- `fogNear` / `fogFar` (default 18/46 — big rooms need ~28–30/80–85)
- `walkSpeed` (default 0.5; big rooms use ~0.6)
- `lights: { hemiSky, hemiGround, hemiIntensity, pointColor, pointIntensity, distance, decay }`
- `fillLights: [ {x,y,z,color,intensity,distance} ]` — add several per zone for brightness

## Conventions / gotchas
- Buildless ES modules + importmap; three r160 vendored at `vendor/three/`.
- Lambert + vertex colours, zero realtime shadows, no purple gradients /
  glassmorphism / bounce (anti-slop).
- `rotY`: 0=+z, 90=+x, 180=-z, 270=-x.
- `kind:'room'` loads a room GLB; `kind:'procedural'` uses `buildRoom` →
  `buildMultiRoom`.
- Library picker needs `library/thumbnails/{id}.png` or the card shows broken.
  Regenerate via `node scripts/generate-thumbnails.mjs <ids>` (repo root; run
  in batches of ≤30 ids).
- Debug hook: `window.__scenarioDebug()` → `{walls, colliders, grabbables,
  anchors, platforms, stateY, groundHeight, championPos, triangles, drawCalls,
  wallOpacities}`; helpers `.tp(x,z)`, `.orbit(theta)`.
- Headless verify: repo-root Playwright chromium — open `/lab/` etc., click
  `.tpl-card` (SAMPLE is first), wait for `__scenarioDebug`, assert no console
  errors / response 404s / `PAGEERROR`.
