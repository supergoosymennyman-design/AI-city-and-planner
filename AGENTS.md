# AGENTS.md — Passiona (AI for Primary 1 and Primary 5)

Passiona is a Hong Kong school **AI-literacy programme**. There are exactly two
programmes:

- **Primary 1 (P1)** — ages 5–6, 20 lessons, playful hands-on AI.
- **Primary 5 (P5)** — ages 9–10, 20 lessons, agentic AI literacy.

Each programme runs on four connected tools: the **AI Workshop** (build an AI
machine), the **Fit Studio** (dress the AI Champion), the **Coding Buddy**
(a bounded agent the child directs) and the **AI City** (the 3D city where built
machines are planted). P1 lesson warm-ups reuse the **kindergarten games**
(sources kept under `source/kindergarten/`).

## Golden rules (summary)

- **Canonical source of truth: `P5 Programme/buddy-kit/client/`.** `deploy/` is
  build output — never edit it for real fixes; it is regenerated by the deploy
  scripts.
- **No child PII.** Camera/mic data stays in-memory; everything is client-side.
- **Models must be CC0 / public domain only.** No attribution-required or
  non-commercial assets.
- **Design quality matters.** Avoid AI-slop (purple gradients, glassmorphism,
  bounce UI, flat type hierarchy); use age-appropriate polish for ~5–6 and
  ~9–10-year-olds.
- **Data-loss safety net.** Student work lives in localStorage/IndexedDB; every
  app offers a bundled Champion File (💾 Save my city) and the city adds cloud
  codes (☁️). Restore must be one tap.

## Tests (from the repo root)

- `npm run test:unit` — node:test suite (`tests/*.test.mjs`).
- `npm run test:library` — shared library integrity audit.
- `npm run test:e2e` — Playwright e2e against a fresh build of the city bundle.
- `npm run test:all` — all of the above.
