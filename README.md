# Passiona — AI for Primary 1 & Primary 5

Passiona teaches AI literacy in Hong Kong primary schools. There are **two
programmes**, each 20 lessons, built on four connected tools — the **AI
Workshop** (build an AI machine), the **Fit Studio** (dress your AI Champion),
the **Coding Buddy** (a bounded agent you direct) and the **AI City** (your 3D
city where built machines are planted):

- **Primary 1 (P1, ages 5–6)** — a playful, hands-on introduction to AI, always
  through touch, sound and pictures, with one clear idea per lesson. P1 lesson
  warm-ups reuse the **kindergarten games** (lesson sources in
  `source/kindergarten/`).
- **Primary 5 (P5, ages 9–10)** — agentic AI literacy: supervised delegation,
  verification, and a finished, evidenced public project.

## Live apps

- **AI City home hub** — "My AI City — Champion Hub", the student entry point:

- **City sim** (planner + Academy pregame + 3D city on one origin):

## Get started

Read **`P5 Programme/AGENTS.md`** first — it is the canonical, authoritative
guide to the code: layout, architecture, tests, deploy and verification.

| Path | What it is |
|---|---|
| `P5 Programme/buddy-kit/client/` | Canonical source (3D AI City, planner, hub) |
| `P5 Programme/docs/` | Programme + architecture docs, `.cap` bridge spec |
| `P5 Programme/deploy/` | Build output — regenerated by deploy scripts, never edit |
| `source/kindergarten/` | P1 warm-up game lesson sources (keep) |
| `platform/` | Experimental Unity build (not the browser city) |
| `tests/` | Node unit tests (`npm run test:unit`) |

## Tests

```bash
npm run test:unit      # node:test suite in tests/
npm run test:all       # unit + library audit + Playwright e2e
```
